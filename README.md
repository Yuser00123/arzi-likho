# ✍️ अर्ज़ी लिखो — Arzi Likho

**12 तरह की सरकारी अर्ज़ियाँ, 3 मिनट में — साइबर कैफ़े / जन सेवा केंद्र की काउंटर के लिए।**

हर छोटे शहर में लोग कैफ़े में आते हैं और ₹30–100 देकर एक टाइप की हुई औपचारिक हिंदी अर्ज़ी लेते हैं —
राशन कार्ड, पेंशन, बिजली बिल, आरटीआई, पुलिस शिकायत, प्रमाण पत्र… कैफ़े संचालक वही चिट्ठे दिन में
बीस बार मेमोरी से टाइप करता है, पता या शुल्क में गलती हो जाती है, और हर अर्ज़ी में 15–20 मिनट लगते हैं।

Arzi Likho उसी काम को 3 मिनट में करता है: काम चुनें → 5–10 ज़रूरी जानकारी भरें → **औपचारिक अर्ज़ी**
(सेवा में / विषय / महोदय / प्रार्थना / भवदीय / संलग्नक) + **"कहाँ जमा करें" बॉक्स** (कार्यालय, पोर्टल,
हेल्पलाइन, शुल्क, समय-सीमा) → प्रिंट / **Word (.docx)** / **English version** / **WhatsApp फॉलो-अप मैसेज**।

## Template लिखते हैं, मॉडल नहीं

यही इस प्रोजेक्ट का दिल है — जो हिस्से **गलत नहीं होने चाहिए**, वे कभी मॉडल से नहीं लिखवाए जाते:

| हिस्सा | कौन लिखता है |
|---|---|
| पता (जिलाधिकारी / पूर्ति अधिकारी / अधिशासी अभियंता / थानाध्यक्ष…) | `forms.py` के टेम्पलेट |
| कानूनी हवाले (आरटीआई धारा 6(1), CrPC धारा 154…), शुल्क, समय-सीमा | `forms.py` |
| "कहाँ जमा करें" — पोर्टल (rtionline, jansunwai, edistrict, sspy…), हेल्पलाइन (1912, 1076, 112, 1967, 1947) | `forms.py` |
| पत्र का ढांचा (तारीख, सेवा में, विषय, प्रार्थना, हस्ताक्षर, संलग्नक) | `letter.py` |
| **बयान** — क्या हुआ, कब से, क्या चाहिए | **Gemma 4** (सिर्फ फ़ॉर्म में दिए तथ्यों से) |
| English version + WhatsApp मैसेज | **Gemma 4** |

जो जानकारी फ़ॉर्म में नहीं भरी, वह अर्ज़ी में **[कोष्ठक]** में खाली दिखती है — कभी गढ़ी नहीं जाती।
मॉडल डाउन हो तो पूरा नमूना-प्रारूप (mock) बन जाता है — काउंटर रुकता नहीं।

## 12 अर्ज़ियाँ

आरटीआई (धारा 6(1)) · आरटीआई पहली अपील (धारा 19(1)) · राशन कार्ड · पेंशन (वृद्धावस्था/विधवा/दिव्यांग) ·
बिजली (बिल/मीटर/कनेक्शन) · पुलिस शिकायत (थानाध्यक्ष, प्रतिलिपि: पुलिस अधीक्षक) · जन-शिकायत
(सड़क/नाली/पानी/बत्ती — शहर में नगर पालिका, गाँव में खंड विकास अधिकारी) · प्रमाण पत्र (आय/निवास/जाति/चरित्र) ·
स्कूल (टीसी/बोनाफाइड/छात्रवृत्ति/फीस माफी) · बैंक (केवाईसी/खाता/एनओसी/गलत कटौती) ·
दस्तावेज़ में सुधार (आधार/मतदाता/मार्कशीट…) · बायोडाटा (विवाह/नौकरी)। जिला-चयन उत्तर प्रदेश के सभी 75 जिलों का।

**कौन भुगतान करेगा:** कैफ़े/जन सेवा केंद्र का संचालक — ₹199/माह जैसी फ़ीस पर, क्योंकि 20 मिनट का काम
3 मिनट का हो जाता है और पता-धारा-शुल्क की गलतियाँ खत्म हो जाती हैं। ग्राहक की फ़ीस वही रहती है (₹30–50)।

## Open क्यों ज़रूरी है

- **ग्राहक का डेटा काउंटर पर रहता है** — `LLM_BASE_URL` को Ollama पर घुमाइए और पूरा ऐप कैफ़े के अपने
  कंप्यूटर पर, बिना इंटरनेट के चलता है। आधार-नंबर, पेंशन फ़ाइल, पुलिस शिकायत — कुछ भी किसी
  तीसरे पक्ष के सर्वर पर नहीं जाता। (डेमो Render + Google AI Studio के free tier पर है — दोनों ही
  मार्ग एक ही कोड से चलते हैं।)
- **प्रति पृष्ठ लागत ₹0** — ₹30 की सेवा पर मीटर वाला API और महीने का बिल मार्जिन खा जाता; खुले वज़न
  (open weights) मौजूदा हार्डवेयर पर चलते हैं।
- **टेम्पलेट ही प्रोडक्ट हैं, और वे editable हैं** — रायबरेली का संचालक `forms.py` खोलकर अपनी तहसील
  या कार्यालय का नाम जोड़ सकता है; किसी vendor की टिकट का इंतज़ार नहीं।
- **जब नेटवर्क नहीं, तब भी** — गाँव के सीएससी 4G पर चलते हैं; मॉडल को इंटरनेट नहीं चाहिए, सिर्फ ई-पोर्टल को चाहिए।

## चलाएँ

```bash
pip install -r requirements.txt
cp .env.example .env            # LLM_API_KEY डालें (Google AI Studio, free) — या LLM_PROVIDER=mock
python app.py                   # http://localhost:7860
python test_app.py              # 10 offline tests — कोई key नहीं, कोई network नहीं
```

**Render पर:** इस repo को fork/clone करके Render पर **New → Blueprint** (`render.yaml` मौजूद है) —
`LLM_API_KEY` environment variable में डालें। Free plan पर ही चल जाता है।

**पूरी तरह offline (कैफ़े के PC पर):**

```bash
ollama pull gemma3:4b
LLM_PROVIDER=openai LLM_BASE_URL=http://localhost:11434/v1 LLM_MODEL=gemma3:4b python app.py
```

## सावधानी (इसीलिए भरोसेमंद)

- यह उपकरण **कानूनी सलाह नहीं** देता — पत्र का ढांचा और जानकारी देता है।
- कार्यालय, शुल्क, समय-सीमा और पोर्टल **बदलते रहते हैं** — हर अर्ज़ी में यही नोट छपता है; जमा करने से
  पहले कार्यालय/जन सुविधा केंद्र से पुष्टि कर लें। (आरटीआई ₹10/30 दिन अधिनियम से आते हैं; बाकी संख्याएँ
  सामान्य मार्गदर्शन हैं।)
- **सर्वर पर कुछ भी संग्रहित नहीं होता** — ड्राफ़्ट केवल उपयोगकर्ता के ब्राउज़र (BrowserState) में रहते हैं।

via किसी भी OpenAI-compatible endpoint (Google AI Studio / **Ollama** / Groq…) · python-docx · Render (free).
